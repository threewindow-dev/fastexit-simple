# 기능목록 (Features) - fastexit

**목적**: fastexit 시스템의 핵심 기능을 정의합니다.

**작성일**: 2026-01-22

**소유자**: Product Owner

---

## 관리자 기능

### F1. 설치자 자동 관리자 승격

**설명**: FastExit 설치 시 처음 가입한 사용자는 자동으로 관리자 권한을 부여받습니다.

**담당자**: Administrator

**관련 개념**: 관리자 (Administrator)

**상태**: 미구현

---

### F2. 금융사 정보 추가

**설명**: 관리자는 자산을 보관할 금융사 정보를 등록합니다.

**입력 정보**:
- 금융사명 (name): 표시명 (예: "삼성증권", "KB증권")
- 금융사 유형 (type): 증권사, 은행, 기타

**담당자**: Administrator

**관련 개념**: 금융사 (Institution)

**상태**: 미구현

---

### F2-1. 상품 등록

**설명**: 관리자는 투자 가능한 상품을 등록/수정합니다. (ETF, 주식, 채권, 통화, 금, 현금, 정기예금, RP, 발행어음 등)

**입력 정보**:
- 상품명 (product_name)
- 자산군 (asset_class)
- 자산 속성 (attributes): 투자 지역, 자산 종류, 화폐, 투자유형, 자산특징, 위험도 등

**담당자**: Administrator

**관련 개념**: 상품 (Product), 자산군 (Asset Class)

**상태**: 미구현

**참고**: Holding 생성 시 반드시 기존 Product를 참조하거나, 신규 Product 등록 후 참조해야 함

---

### F3. 계좌 추가

**설명**: 관리자는 등록된 금융사에 계좌를 추가합니다.

**입력 정보**:
- 금융사 선택 (institution)
- 계좌명 (name): 사용자 정의 이름
- 계좌 유형 (type): ISA, CMA, 일반 증권, 예금, 연금저축 등
- (선택) 참조용 계좌번호: 식별에는 사용하지 않음

**담당자**: Administrator

**관련 개념**: 계좌 (Account)

**상태**: 미구현

---

### F4. 자산 추가

**설명**: 관리자는 등록된 계좌에 자산을 추가합니다.

**입력 정보**:
- 계좌 선택 (account)
- 상품 선택 (product) — product_id로 참조
- (평가금액은 스냅샷 시점에서 입력)

**담당자**: Administrator

**관련 개념**: 자산 (Holding), 상품 (Product), 자산군 (Asset Class)

**상태**: 미구현

---

### F4-1. 일반 스냅샷 생성 및 평가금액 입력

**설명**: 관리자가 일반 스냅샷을 수동 생성하고 자산별 평가금액을 입력한 뒤 잠금으로 확정합니다.

**입력 정보**:
- 일반 스냅샷 기준일 (reference_date) 생성
- 자산 선택 (holding) 및 평가금액 (valuation_amount)
- 잠금 여부 (lock): 입력 완료 후 확정

**담당자**: Administrator

**관련 개념**: 일반 스냅샷, 자산 (Holding), 금액 (Money)

**상태**: 미구현

**참고**: 잠금된 일반 스냅샷이 주간/연간 스냅샷의 원본이 됩니다.

---

### F4-4. 자산 삭제 (2단계)

**설명**: 관리자는 자산을 두 단계로 삭제할 수 있습니다.

**단계**:
- 1단계: 숨김(Hide) — 일반 사용자에게 보이지 않도록 처리 (집계/조회에서 제외)
- 2단계: 완전 삭제(Hard Delete) — 자산 레코드를 영구 삭제 (관리자만 가능)

**입력 정보**:
- 자산 선택 (holding)
- 삭제 단계 선택 (hide | hard_delete)
- 삭제 사유 (optional)

**제약/효과**:
- 숨김 처리된 자산은 향후 생성되는 스냅샷과 합계에서 제외
- 이미 생성된 과거 스냅샷은 불변으로 유지 (당시 상태 보존)
- 완전 삭제는 감사 로그 기록 권장

**담당자**: Administrator

**관련 개념**: 자산 (Holding), 스냅샷 (Snapshot)

**상태**: 미구현

---

### F4-2. 주간 스냅샷 생성 (수동)

**설명**: 관리자가 토요일에 버튼을 눌러 주간 스냅샷을 수동 생성합니다.

**생성 규칙**:
- 실행 시점: 토요일, 관리자 트리거
- 원본: 최근 1주일 내 잠금된 가장 최근 일반 스냅샷
- 기준일: 스냅샷 생성 요청일(토요일)
- 내용: 기준일 현재의 모든 계좌, 자산, 평가금액

**수정 가능 기한**: 다음 주간 스냅샷이 생성될 때까지 (최대 1주)

**담당자**: Administrator

**관련 개념**: 주간 스냅샷 (Weekly Snapshot), 일반 스냅샷 (Snapshot)

**상태**: 미구현

---

### F4-3. 연간 스냅샷 생성 (수동)

**설명**: 관리자가 1월 1~7일 사이에 버튼을 눌러 연간 스냅샷을 수동 생성합니다.

**생성 규칙**:
- 실행 시점: 1월 1~7일, 관리자 트리거
- 원본: 1월 1일에 가장 가까운 날짜의 잠금된 일반 스냅샷
- 기준일: 1월 1일
- 내용: 기준일 현재의 모든 계좌, 자산, 평가금액

**수정 가능 기한**: 생성 후 1주일 (1월 1일 ~ 1월 7일 자정)

**담당자**: Administrator

**관련 개념**: 연간 스냅샷 (Annual Snapshot), 일반 스냅샷 (Snapshot)

**상태**: 미구현

---

### F7. 계좌 그룹화

**설명**: 관리자는 서로 다른 금융사에 개설된 계좌들을 하나의 그룹으로 설정할 수 있습니다.

**입력 정보**:
- 그룹명 (group_name): 사용자 정의 이름
- 포함 계좌 (accounts): 1개 이상의 계좌 선택
  - 같은 금융사 계좌 포함 가능
  - 다른 금융사 계좌도 포함 가능

**담당자**: Administrator

**관련 개념**: 계좌 그룹 (Account Group)

**상태**: 미구현

**참고**: 계좌 그룹은 사용자 정의 가능한 논리적 그룹핑입니다.

## 사용자 기능

### F5. 계좌별 자산 평가금액 주간 조회

**설명**: 로그인한 사용자는 계좌별로 자산의 평가금액 합계를 주 단위로 조회합니다.

**조회 조건**:
- 기준일: 토요일 (스냅샷 기준일)
- 범위: 선택 가능한 기간 (최근 N주, 특정 기간)
- 정렬: 금융사별, 계좌별

**출력 정보**:
- 금융사명
- 계좌명
- 계좌별 총 평가금액
- 기준일

**담당자**: Logged-in User

**관련 개념**: 주간 스냅샷 (Weekly Snapshot), 자산 현황 (Asset Status)

**상태**: 미구현

---

### F6. 계좌별 자산 평가금액 연간 조회

**설명**: 로그인한 사용자는 계좌별로 자산의 평가금액 합계를 연 단위로 조회합니다.

**조회 조건**:
- 기준일: 1월 1일 (스냅샷 기준일)
- 범위: 선택 가능한 연도 (최근 N년, 특정 연도)
- 정렬: 금융사별, 계좌별

**출력 정보**:
- 금융사명
- 계좌명
- 계좌별 총 평가금액
- 기준일 (연도)

**담당자**: Logged-in User

**관련 개념**: 연간 스냅샷 (Annual Snapshot), 자산 현황 (Asset Status)

**상태**: 미구현

---

### F8. 계좌 그룹별 주간 조회

**설명**: 로그인한 사용자는 관리자가 정의한 계좌 그룹으로 정렬된 상태로 주 단위 조회를 할 수 있습니다.

**조회 조건**:
- 기준일: 토요일 (스냅샷 기준일)
- 범위: 선택 가능한 기간
- 정렬: 계좌 그룹별, 그룹 내 계좌별

**출력 정보**:
- 계좌 그룹명
  - 그룹 내 각 계좌
    - 금융사명
    - 계좌명
    - 계좌별 총 평가금액
  - 그룹별 소계
- 기준일

**담당자**: Logged-in User

**관련 개념**: 계좌 그룹 (Account Group), 주간 스냅샷 (Weekly Snapshot)

**상태**: 미구현

---

### F9. 자산군별 집계 조회

**설명**: 로그인한 사용자는 자산군(자산 클래스)에 따라 집계된 자산 현황을 조회할 수 있습니다.

**조회 조건**:
- 자산군 선택: 주식, 채권, 통화, 금, 부동산, 가상자산, 기타자산 등
- 기준일: 특정 스냅샷 기준일 선택 (주간/연간)

**출력 정보**:
- 자산군별 그룹
  - 각 상품명
    - 평가금액
  - 자산군별 소계
- 전체 자산 총액

**담당자**: Logged-in User

**관련 개념**: 자산군 (Asset Class), 자산 (Holding), 스냅샷 (Snapshot)

**상태**: 미구현
